## 🏗️ Architecture Overview

### Tech Stack
- **Runtime:** Node.js 20+, TypeScript 5.x
- **API Framework:** Express.js with TypeScript
- **Database:** PostgreSQL 16
- **Cache:** Redis 7
- **ORM:** Prisma 5.x
- **Validation:** Zod
- **Testing:** Jest

- **32 Strategic Indexes** for query optimization
- **Repository Pattern** for clean data access
- **Type-Safe Validation** with Zod schemas

## 🚀 Quick Start

### Prerequisites
- Node.js 20+
- Docker Desktop
- npm 10+

### Installation

```bash
# Clone repository
git clone https://github.com/iamthegreatdestroyer/AutoAG-CommGateway.git
cd AutoAG-CommGateway

# Install dependencies
npm install

# Configure environment
cp .env.example .env
# Edit .env with your settings

# Start Docker services
cd docker
docker-compose up -d

# Apply database migrations
cd ..
npx prisma migrate reset --force
npx prisma generate

# Seed database
npm run seed

# Build project
npm run build

# Start API server
npm start
```

### Development Mode

```bash
# Start in watch mode
npm run dev

# Run tests
npm test
npm run test:integration
npm run test:e2e

# Lint & format
npm run lint
npm run format
```

## 🗄️ Database Schema

### Core Entities

#### User Management
- **User** - Authentication, roles (USER, DEVELOPER, ADMIN), wallet
- **ApiKey** - Scoped API keys with rate limiting

#### MCP Marketplace
- **MCPServer** - Server registry with health monitoring
- **Tool** - Tool catalog with JSON Schema validation
- **Invocation** - Execution tracking and performance metrics

#### Monetization (x402 Integration - Phase 5)

## 📡 API Endpoints (Phase 3 - Upcoming)

### Authentication
- `POST /api/auth/register` - Create user account
- `POST /api/auth/login` - Authenticate user
- `POST /api/auth/refresh` - Refresh JWT token

### MCP Servers
- `GET /api/servers` - Search servers
- `POST /api/servers` - Register server
- `GET /api/servers/:id` - Get server details
- `PUT /api/servers/:id` - Update server
- `POST /api/servers/:id/publish` - Publish server

### Tools
- `GET /api/servers/:id/tools` - List tools
- `POST /api/servers/:id/tools` - Create tool
- `POST /api/tools/:id/invoke` - Invoke tool
