## Port Range Rationale

✅ **18500-18599 Selected Because:**
- Clear separation from all existing projects
- Memorable sequence (185xx)
- Room for 100 services (plenty for future expansion)
- No conflicts with common service defaults
- Professional range (not in ephemeral port territory)

## Firewall Notes

If deploying to production, ensure these ports are:
- ✅ Open on local firewall (Windows Defender)
- ✅ Configured in cloud security groups (if applicable)
- ⚠️ Only expose API Gateway (18500) and Nginx (18530) publicly
- 🔒 Keep all other ports internal/VPC-only
